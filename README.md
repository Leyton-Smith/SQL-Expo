# SQL Retail & Sales Data Analysis Project

## Overview

This project was completed as part of a Data Technician Bootcamp and demonstrates practical SQL skills used to analyse, organise, and extract insights from retail and sales datasets. The work involved querying relational databases, filtering records, aggregating data, and joining multiple tables to answer business questions and support data-driven decision making.

## Skills Demonstrated

### Data Retrieval & Filtering
- Used `SELECT` statements to retrieve specific columns and datasets.
- Applied `WHERE` clauses to filter records based on defined conditions.
- Used `DISTINCT` to remove duplicate results and improve data quality.

### Sorting & Organising Data
- Implemented `ORDER BY` to sort results in both ascending and descending order.
- Analysed ranked datasets such as language percentages, sales values, and population statistics.

### Data Aggregation
- Used `GROUP BY` to summarise data at country, customer, and product levels.
- Applied aggregate functions including:
  - `COUNT()`
  - `SUM()`
  - `AVG()`
  - `MAX()`
- Used `HAVING` clauses to filter grouped results and identify trends.

### Table Relationships & JOINs
- Worked with relational database concepts including primary and foreign keys.
- Implemented various SQL JOIN operations:
  - `INNER JOIN`
  - `LEFT JOIN`
  - `RIGHT JOIN`
  - `FULL JOIN`
  - `SELF JOIN`
  - `CROSS JOIN`
- Combined data from multiple tables to create more meaningful business insights and understand relationships between customers, sales, products, and suppliers.

### Advanced Querying
- Created subqueries to perform more complex data analysis.
- Used conditional logic and filtering to identify patterns and anomalies.
- Performed data quality checks and validation through SQL queries.

## Key Learning Outcomes

Through this project, SQL was used to analyse retail and sales data by:

- Identifying sales trends and customer activity.
- Summarising performance metrics through grouped data.
- Extracting meaningful business insights from large datasets.
- Understanding how relational databases store and connect information.
- Improving data accuracy through the use of keys and table relationships.
- Developing confidence in writing, debugging, and optimising SQL queries.

## Project Outcome

This project strengthened my ability to work with relational databases and use SQL as a tool for data analysis. By applying querying, filtering, aggregation, and JOIN techniques, I was able to transform raw retail and sales data into actionable insights that support informed business decisions.
